Methodology Notes

Scoring: Each checklist header carries a headline score (e.g. SCORE- 70% or FINAL SCORE:34). Where the same POD also appears in the Summary sheet, that sheet's independently-recorded Audit Score is treated as authoritative and shown as Score % (cross-verified to match the header text read as a literal percentage). Otherwise the header value is used directly.

POD name matching: POD names are matched between checklist files and the Summary sheet using exact match, substring containment, then fuzzy (typo-tolerant) matching, since several entries contain spelling variants (e.g. "Kriloskar Colony" vs "Kirloskar Colony", "Malleswarm west" vs "Malleswaram West").

Categories: Category labels follow the master checklist template ("NEW Auditchecklist" CSV) verbatim — the same 12 categories every Format A audit uses (FNV, Dairy/Batter/Beverage/Sweets Etc., Dairy/Meats, Ice creams/Indain Sweets/Instant & Frozen Food, Ice Cream/Frozen Food, Munchies And Snacks/Chocolates/Biscuits & Cakes, Bread/ Eggs/ Munchies And Snacks/Atta, RIce & Dals Etc., Bread/ Eggs, FNV NOICE & Other Brands, Nectr & Other FNV, Noice, Other Brands). Format B's simplified one-word categories (Dairy, Bread, Eggs, Fresh & Frozen Meat) are mapped to the master category covering the same checkpoints rather than kept as separate labels. The original raw label from each source file is preserved in the underlying data as categoryRaw.

Format column: not a business category — it labels which of two CSV template layouts a given audit file used. Format A is the 10-column layout (separate Zone/Brand/Sample Size columns, 44 checkpoints). Format B is the simpler 7–8 column layout (combined Nectr/Noice vs. Other-brand observation columns, 27–28 checkpoints). The questions and 0–2 scoring scale are identical either way — it's shown for reference only in the leaderboard table and is not filterable.

All original CSV files are left untouched in the source folder. This dashboard, the parser script, and the parsed JSON data are saved in the dashboard_output subfolder.
